# 🚀 3D-Startup-App

A modern and interactive **3D startup landing page** designed for developers. The website combines a futuristic dark UI with a 3D Spline model, smooth animations, glowing effects, and responsive layouts.

## ✨ Features

* 🧊 Interactive 3D Spline model
* 🎨 Modern dark and purple gradient UI
* ⚡ Smooth AOS scroll animations
* ✨ Animated floating particles
* 📱 Responsive design with mobile hamburger menu
* 🚀 Hero section with call-to-action buttons
* 💎 Feature cards with hover effects
* 💰 Starter, Pro, and Enterprise pricing plans
* 📩 Interactive contact form
* 📖 Developer documentation/resources section
* 🌌 Animated background gradients
* 🔗 Smooth scrolling navigation

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Spline 3D Viewer
* AOS (Animate On Scroll)
* Font Awesome

## 🚀 Getting Started

1. Clone or download the repository.

2. Open the project folder.

3. Make sure `index.html` and `style.css` are in the correct location.

4. Open `index.html` in your browser.

For the best development experience, use **VS Code with Live Server**.

## 🌐 External Resources

This project uses external CDN resources for:

* Spline 3D Viewer
* AOS animations
* Font Awesome icons

An internet connection may be required for these resources to load.

## 📱 Responsive Design

The website is optimized for different screen sizes, including desktop, tablet, and mobile devices. On smaller screens, the navigation changes into a hamburger menu and the content/layout adapts accordingly.
